# /next-prompt — 새 세션용 인계 프롬프트 생성

컨텍스트가 차오르면 하네스가 자동 요약하지만, 그 과정에서 **왜 그렇게 정했는지**가 먼저 날아간다.
이 명령은 지금 대화에서 *파일로 복구할 수 없는 것*만 뽑아 새 세션에 붙여넣을 프롬프트를 만든다.

---

## 원칙 (CRITICAL)

**파일에서 복구 가능한 것은 담지 않는다.** 새 세션도 코드를 읽을 수 있다.

| 담지 않는다 | 담는다 |
|---|---|
| 코드 본문, 파일 구조, 디렉토리 트리 | **결정과 그 이유** |
| `git log`로 알 수 있는 것 | **시도했다 버린 것과 왜** (architecture.md §5) |
| README·CLAUDE.md에 이미 있는 것 | 이번에 걸린 **함정** |
| 대화의 시간순 재현 | 아직 **미해결인 질문** |

두 번째 원칙: **지어내지 않는다.** 대화에 없던 결정을 그럴듯하게 채우면
새 세션이 그걸 확정 사실로 믿고 움직인다. 없으면 "없음"이라고 적는다.

---

## 0단계: 인자 파싱

인자가 있으면 그 방향을 **"다음에 할 일"의 초점**으로 삼는다.

```
/next-prompt                          → 대화 전체에서 자동 판단
/next-prompt "테스트부터 붙이고 싶어"   → 다음 액션을 그쪽으로 좁힘
```

---

## 1단계: 사실 수집 (추측 금지)

```bash
git branch --show-current
git log --oneline -10
git status --short
git diff --stat HEAD
```

추가로 확인한다:
- `plan.md` / `prompt_plan.md` / `spec.md` 존재 여부와 STATUS
- **이번 세션에서 실제로 편집한 파일** — 대화 기록 기준. git status와 대조해 어긋나면 그대로 보고

---

## 2단계: 대화에서 5가지를 추출

각 항목은 **대화에 근거가 있을 때만** 적는다. 근거가 없으면 그 절을 통째로 생략한다.

1. **목표** — 이 세션이 무엇을 하려 했나 (1-2문장)
2. **완료** — 무엇이 실제로 끝났나. **검증 증거를 함께 적는다.**
   실행 결과 없이 끝났다면 `(미검증)`이라고 명시한다 (verification.md)
3. **결정** — 무엇을, **왜** 그렇게 정했나. 이유가 핵심이다.
   이유 없는 결정은 새 세션이 곧바로 재논의한다
4. **폐기** — 시도했다 버린 것 + 버린 이유. 없으면 생략
5. **함정** — 이번에 걸린 것. 다음 세션도 똑같이 걸릴 것

---

## 3단계: 프롬프트 조립

아래 형식으로 만든다. **빈 절은 넣지 않는다.**

````markdown
## 배경
[저장소·프로젝트, 무엇을 하는 중인지 2-3문장]

## 지금 상태
- 브랜치: [X] (최근 커밋 [해시] [제목])
- 바뀐 것: [파일] — [한 줄 설명]
- 미커밋: [있으면 목록, 없으면 "없음"]
- 검증: [실행한 것 / 안 한 것]

## 이미 정해진 것 — 다시 논의하지 말 것
- [결정] — 이유: [왜]

## 시도했다 버린 것 — 다시 만들지 말 것
- [무엇] — 버린 이유: [왜]

## 알아둘 함정
- [함정]

## 미해결 (사용자 확인 필요)
- [질문]

## 다음에 할 일
1. [액션]
2. [액션]

## 먼저 읽을 파일
- `경로` — [왜 읽어야 하는지]

---
위 배경을 먼저 확인하고, **진행 방향이 맞는지 나에게 한 번 물어본 뒤** 시작해줘.
````

「이미 정해진 것 — 다시 논의하지 말 것」이 이 프롬프트에서 가장 값어치 있는 절이다.
새 세션이 이미 끝난 논의를 되풀이하는 게 가장 큰 낭비다.

---

## 4단계: 클립보드로 내보내기

프롬프트 **본문만**(설명·인사말 없이) 클립보드에 넣는다.

```bash
pbcopy <<'PROMPT_EOF'
[3단계에서 조립한 본문]
PROMPT_EOF
```

`pbcopy`가 없으면 순서대로 시도하고, 전부 없으면 화면 출력만 한다:
`xclip -selection clipboard` → `clip.exe` → 화면 출력

---

## 5단계: 자기 점검 (출력 전 필수)

- [ ] 코드 본문을 복붙하지 않았는가 (경로만 남겼는가)
- [ ] 대화에 없던 결정·이유를 지어내지 않았는가
- [ ] 각 결정에 **왜**가 붙어 있는가
- [ ] 검증 안 한 것을 완료로 적지 않았는가
- [ ] 새 세션이 **이것만 읽고** 시작할 수 있는가
- [ ] 100줄을 넘지 않는가 (넘으면 결정·함정 위주로 줄인다)

하나라도 어긋나면 고친 뒤 출력한다.

---

## 6단계: 출력

```
════════════════════════════════════════════════════════════════
  Next Prompt — 새 세션 인계
════════════════════════════════════════════════════════════════

  클립보드에 복사됨 ([N]줄)

  담긴 것: 결정 [N]건 / 폐기 [N]건 / 함정 [N]건 / 다음 액션 [N]건
  뺀 것:   코드 본문, 파일 구조 (새 세션이 직접 읽음)

  ── 미리보기 ─────────────────────────────────────────────────
  [프롬프트 전문]
  ────────────────────────────────────────────────────────────

  사용법: 새 세션을 열고 Cmd+V

════════════════════════════════════════════════════════════════
```

클립보드 복사에 실패했으면 그 사실을 **명시**하고 수동 복사를 안내한다.
